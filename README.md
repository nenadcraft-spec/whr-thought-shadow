# WHR Thought Shadow / Thought Echo

**Status:** Open concept / Build-Up Memory checkpoint  
**License intent:** Open sharing / open-source direction  
**Authors:** Beli Zec + Ćale / WHR Studio

## Core idea

A reflective AI layer between the user and model:

```text
USER
↓
INTENT
↓
SHADOW
↓
COUNTER-CHECK
↓
AI
↓
PROCESSING
↓
SHADOW REFLECTION
↓
USER
```

### Thought Shadow

```text
THOUGHT_SHADOW
= what a thought produces
  but the thought itself does not directly see
```

### Thought Echo

```text
THOUGHT_ECHO
= THOUGHT
+ FAMILIARITY SIGNAL
+ INTUITIVE SIGNAL
```

Thought Echo is a **signal, not evidence**.

### Shadow of Shadow

```text
SHADOW_OF_SHADOW
= CHECK_THE_CHECK
= META_QA
```

Meta-depth must be limited to avoid infinite self-review.

## Light model

```text
LIGHT_OF_THOUGHT = FEEDBACK
FRICTION_WITH_REALITY = STRONGEST_FORM_OF_FEEDBACK
```

Feedback may also come from:

- another human
- another agent
- new evidence
- a counterexample
- an internal contradiction
- experience
- testing
- changed context

## Accessibility root

This line of thought started with a practical accessibility problem:

```text
BODY_SIGNAL ≠ COMMAND
UNCLEAR_INPUT → HOLD
RISKY_ACTION → CONFIRM
```

The interface should adapt to the human rather than demanding that every human use the same input mode.

## Safety

```text
DEJA_VU ≠ EVIDENCE
INTUITION ≠ FACT
ECHO ≠ TRUTH
SHADOW ≠ TRUTH
COUNTERARGUMENT ≠ AUTOMATICALLY CORRECT
META_CHECK ≠ GUARANTEE
AUTO_GUESS = BLOCKED
USER = FINAL DECISION
```
