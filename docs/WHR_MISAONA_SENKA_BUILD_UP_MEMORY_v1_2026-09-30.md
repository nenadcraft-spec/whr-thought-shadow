## 5. SENKA

Iz kontra-korisnika nastaje naziv:

```text

```

Arhitektura:

```text
KORISNIK ↔ SENKA ↔ AI
```

Senka nije kopija korisnika.

Senka je:

```text

KONTRA-SIGNAL

```

Primeri:

```text

→ SENKA TRAŽI KONTRA-UGAO

→ SENKA PITA: "DOKAZ?"

```



```text

REZULTAT = SENKA_1

SVETLOST_2 = NOVA INFORMACIJA / META-PROVERA
OBJEKAT_2 = SENKA_1
REZULTAT = SENKA_SENKE
```

Radna definicija:

```text

```

